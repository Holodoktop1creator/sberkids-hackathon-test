Новый объект по картинке

Перетащите PNG или SVG с прозрачным фоном. Игра сама обрежет поля, посчитает пропорции и перекрасит силуэт. Заполните поля и нажмите «Добавить в игру» — объект появится в своей вкладке, в черновике игры и, после «Опубликовать», у детей.

📂 Перетащите файл сюда или нажмите, чтобы выбрать

Вещь с ценой — это цель (самокат, смартфон) или понятная единица (мороженое, пицца). У единицы заполните «Покупают раз в неделю» и «Копить без…»: из них игра считает «самокат = 40 мороженых = почти 2 месяца без мороженого». Как считать — три формы через запятую: для 1, для 2 и для 5 штук.

🚀 Опубликовать в игру

Игра берёт контент из папки , которую раздаёт GitHub Pages. Публикация положит туда ваши правки одним коммитом — дети увидят их при следующем запуске игры, обычно через минуту. Свой сервер не нужен, релиз приложения — тоже.

Нужен fine-grained токен с доступом только к этому репозиторию и правом Contents: Read and write — создать на GitHub. Токен хранится только в этом браузере и отправляется только в API GitHub.
