# «Прикинь!» — звери и страны в настоящем размере

Хакатон Сбер × ВШЭ «Создаем эмоции», **трек B · Игры**. Вертикальная 2D-игра для детей 10–13 лет в духе [Size It Up](https://sizeitup.games/animals).

**Играть:** https://holodoktop1creator.github.io/sberkids-hackathon-test/game/ (эту ссылку можно вставить в песочницу)

Чёрный силуэт — эталон в настоящем масштабе: человек, кошка, США. Белый силуэт — твоя догадка: свайпаешь по доске вверх-вниз, и он растёт или сжимается. Жмёшь «ФИКСИРУЮ!» — поверх появляется розовый пунктир правильного размера, очки, «Чего?!»-факт и объяснение «во сколько раз».

Насколько длинная косатка рядом с белой акулой? Страус выше человека? Во сколько раз Африка больше Гренландии, которая на обычной карте выглядит такой же?

## Учебная цель

> **После игры ребёнок прикидывает размеры через «во сколько раз» с опорой на эталон и не верит картинке на глаз: знает, что плоские карты искажают размеры стран, а площадь растёт быстрее, чем длина.**

Это **критическое мышление** (домен «мягкие навыки» из брифа) плюс чувство числа. Механика и есть применение знания: на глаз без сравнения с эталоном угадать нельзя, а фото зверей и карты, которые ребёнок видел раньше, систематически обманывают.

**Как понять, что научился:** растёт точность на парах, которых ребёнок раньше не видел, и после промаха он попадает в **реванш** — та же цель против другого эталона.

## Механика

1. **Заставка VS:** «КОСАТКА vs БЕЛАЯ АКУЛА», с ударом и звуком.
2. **Доска.** Эталон и догадка нарисованы в одном масштабе. Камера сама отъезжает, если силуэт стал огромным, внизу живая линейка (10 см, 2 м, 1000 км). Высоких зверей сравниваем рядом на общей земле, длинных — друг под другом от одного края, страны — по площади.
3. **Очки как в Size It Up:** точность ±6% даёт 100, ошибка в 2 раза — ~45, в 5 раз — 0. Из 8 раундов два **босс-раунда ×2** с самыми коварными парами, максимум 1000.
4. **Ошибку объясняем:** «Правильно: Косатка = 1,6 × Белая акула · У тебя: 1,1 × · Промах: размер в 1,5 раза меньше» + факт + подсказка, как прикидывать.
5. **Реванш:** при промахе цель возвращается позже с другим эталоном — ребёнок применяет то, что только что узнал.
6. **Секундомер** в углу доски: тикает с первой секунды хода, после фиксации время попадает в результат («⏱ 3,4 с · ⚡ Молния!»), в итоги и в карточку «поделиться». Он считает **вверх** и не даёт штрафов: по ТЗ обратный отсчёт и давление срочностью запрещены, поэтому скорость — повод для азарта и спидрана, а не угроза.
7. **Крестик ✕** всегда в левом верхнем углу на любом экране — закрывает игру.

## Почему это зайдёт поколению Альфа (10–13)

- **Быстро и ярко.** Раунд длится 10–20 секунд, заход — 3–4 минуты. Заставки VS, удары и встряски, конфетти, комбо-серия «🔥 ×3», мигающий босс-раунд, живой секундомер и бейдж «⚡ Молния!» за быстрый точный ответ.
- **Ощущение «ЧЕГО?!».** Велоцираптор размером с индюка, страус выше баскетболиста, Африка в 14 раз больше Гренландии. Удивление и неожиданность — то, что эта аудитория «съедает» (исследование из брифа).
- **Животные и смешное** — топ-темы контента у детей. Капибара Капи — наш собственный персонаж-ведущий.
- **Соревнование и статус (11–14 лет).** Дуэль, титулы («Глаз-алмаз», «Легенда прикидки»), рекорд сессии.
- **Коллекция (8–10 лет).** Гардероб Капи: апельсинка, очки, медаль и корона за очки.
- **Повод поделиться:** карточка результата с квадратиками в стиле Wordle 🟩🟨🟧⬜ и вызовом «Сможешь прикинуть точнее? 😏».

## Педагогика

- **Сравнение с эталоном** (benchmark estimation) — основной приём развития чувства числа и масштаба.
- **Мультипликативное мышление:** ответ всегда формулируется как «во сколько раз», а не «на сколько».
- **Мгновенная обратная связь** с объяснением и **реванш** (интервальное повторение плюс перенос на новый эталон).
- **Критическое отношение к визуальной информации:** проекция Меркатора, квадратичный рост площади.
- **Обучение со сверстниками** в дуэли: дети спорят и объясняют друг другу.

| Сессия 3–5 мин, можно переиграть | 8 раундов, «Ещё раз» генерирует новые пары |
| Звук не запускается сам, есть переключатель | Только в ответ на действие, кнопка 🔊/🔇 |
| Нет лотереи, тёмных паттернов, таймеров | Нет обратного отсчёта и «ещё попытки за…». Награды открываются за очки, пороги видны заранее |
| Нет брендов, чужой ИП, оружия | Собственный персонаж. Силуэты только CC0 и Public Domain, контуры — Natural Earth (public domain), см. [CREDITS](game/content/CREDITS.md) |
| Без спорных границ | Страны со спорными границами не используем — только бесспорные и континенты |

| Битый конфиг не ломает игру | Каждая запись проверяется. Если файл не загрузился, остаются доступные режимы, иначе — экран «Ещё раз» |

## Связь с приложением

| Событие | Когда |
|---|---|
| `CLOSE_EVENT` | Крестик ✕ в левом верхнем углу (если игру открыли не в приложении, он возвращает в меню) |
| `FINISH_EVENT` | Конец каждого захода (одиночного и дуэли) |
| `COMPLETED_EVENT` | Конец первого одиночного захода, **один раз** за открытие |
| `VIBRATION_EVENT` | Попадание ≥ 85 очков, тап по Капи |
| `SHARING_EVENT` | «Кинуть результат другу»: `text` + `image` (JPEG data URL карточки). Карточка сразу показывается и в игре, чтобы кнопка давала видимый результат даже вне приложения |

## Управление контентом (без релиза)

Всё лежит в `game/content/` и меняется на CDN без релиза:

- [`game.json`](game/content/game.json) — число раундов, босс-раунды, пары-ловушки, ранги, титулы, пороги гардероба, подсказки, уроки;
- [`animals.json`](game/content/animals.json) — звери: имя, размер, измерение (`long` / `tail` / `tall`), факт, силуэт;
- [`countries.json`](game/content/countries.json) — страны: имя, площадь, факт, контур.

Пары собираются автоматически из любых двух объектов, если они отличаются в разумное число раз (`ratio` в `game.json`). Новый зверь или страна сразу участвуют в игре.

Сборка ресурсов (нужна только для обновления силуэтов и контуров):

```bash
python tools/build_animals.py raw                                         # скачать силуэты PhyloPic (CC0/PD)
python tools/build_animals.py final tools/bbox.json game/content/animals.json  # рамки считает tools/bbox.html
python tools/build_countries.py ne_50m_admin_0_countries.geojson game/content/countries.json
```

## Запуск

```bash
cd game
python -m http.server 8080
```

Откройте `http://<IP ноутбука>:8080` в песочнице ([Android](https://github.com/vveidi/sber-hse-hackathon-2026-android) / [iOS](https://github.com/vveidi/sber-hse-hackathon-2026-ios)). Параметр `?debug` показывает каждое отправленное событие.
