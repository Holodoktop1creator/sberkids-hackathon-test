# СберKids Хакатон — тестовый репозиторий

Стартовый шаблон для трека **«Игры»** (HTML5-игра для WebView приложения СберKids).

## Ограничения трека
- Чистый HTML, CSS и JavaScript — **без библиотек и фреймворков**.
- **Полная изоляция**: никаких внешних API, CDN-скриптов, шрифтов с чужих хостов, аналитики, iframe и ссылок наружу.
- Все файлы рядом с игрой, ссылки **относительные**.
- Бюджеты: **≤ 5 МБ** вес, **≤ 3 с** до первого играбельного экрана, **60 fps**.
- Аудитория 6–13 лет, возрастная категория 0+/6+ (436-ФЗ).
- Состояние — только в хранилище страницы на одну сессию.

## События для приложения
```js
window.postMessage({ type: "CLOSE_EVENT" }, "*");
```
| Событие | Значение |
|---|---|
| `CLOSE_EVENT` | закрыть экран игры |
| `FINISH_EVENT` | игра завершена |
| `COMPLETED_EVENT` | игра пройдена |
| `VIBRATION_EVENT` | тактильный отклик |
| `SHARING_EVENT` | поделиться |

## Запуск локально
```bash
npx serve game
```
или просто откройте `game/index.html` в браузере. Обязательно проверьте на телефоне (Android и iOS WebView).

## Структура
```
game/

```
