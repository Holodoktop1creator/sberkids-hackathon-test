# «Прикинь!» — игра для СберKids

Хакатон Сбер × ВШЭ «Создаем эмоции», **трек B · Игры**.

Вертикальная 2D-игра для детей 10–13 лет в духе Size It Up. Ребёнок **тянет башню из монет или блоков**, пока её высота не совпадёт с правильным ответом: сколько шоколадок стоят наушники, сколько недель копить на самокат, сколько на самом деле стоит покупка в кредит и сколько вернёт «незнакомец, который обещает удвоить». Потом рядом вырастает башня-ответ, и всё видно сразу.

Ведущая — капибара **Капи**, наш собственный персонаж.

## Учебная цель

> **После игры ребёнок умеет прикинуть, сколько недель копить на покупку, сколько на самом деле стоят скидка, подписка и кредит, и отличает сообщение мошенника от настоящего перевода.**

**Как понять, что научился:** ребёнок ставит башню с точностью до 5% на задании, которого раньше не видел (новый заход берёт другие задания), а во «Входящих» опускает башню мошенника до нуля и при этом не трогает настоящий перевод от бабушки.

## Механика

1. Капи задаёт вопрос. В главе «Входящие» вопросу предшествует сообщение из чата.
2. Ребёнок тянет башню вверх-вниз пальцем (или кнопками −/+). Рядом стоит **башня-эталон**, например «10 шоколадок = 1 000 ₽» или «1 неделя = 300 ₽»: по ней можно прикинуть масштаб.
3. «Готово!»: вырастает башня-ответ, появляется линия правильного ответа, начисляются звёзды за точность (≤5% → ⭐⭐⭐, ≤15% → ⭐⭐, ≤30% → ⭐).
4. **Ошибку не наказываем, а объясняем.** Блок «Как считать» показывает решение, кнопка «Ещё раз» даёт новую попытку, в зачёт идёт лучший результат.
5. **Ловушки.** Если ребёнок поверил мошеннику, башня рушится и монеты разлетаются, но без запугивания: «Ловушка! Теперь ты её знаешь». Если не поверил, получает **щит-правило** («🔐 Код из СМС — никому»).

Пройти игру, не поняв тему, нельзя. Ответ всегда надо посчитать или распознать: во «Входящих» есть и мошенники (ответ 0), и честные переводы от родных (ответ не 0), поэтому стратегия «всегда ставь ноль» не работает.

### Главы («выставки», как в Size It Up)

| Глава | Что тренирует |
|---|---|
| ⚖️ Цена и ценность | Цена в понятных вещах: наушники = 25 шоколадок. Чем жертвуешь ради покупки |
| 🫙 Копилка | Планирование: (цена − что уже есть) ÷ сколько откладываешь в неделю |
| 🏷️ Хитрые цены | Скидки в %, акции «3 по цене 2», подписки, «латте-эффект» мелких трат |
| 🏦 Вклад и кредит | Проценты по вкладу, переплата по кредиту |
| 📩 Входящие | Скам, «код из СМС», «мама с нового номера», фейковые розыгрыши, дропперство, кража аккаунта |

### Заход = 3–5 минут

8 заданий из разных глав, каждый раз новые. Сессия заканчивается итогом: звёзды, титул («Глаз-алмаз», «Финансовый вайб-мастер»…), шкала из цветных квадратиков 🟩🟨🟧⬜, собранные щиты и короткий список «Что теперь умеешь».

## Почему это зайдёт детям 10–13 (поколение Альфа)

Опираемся на исследование из брифа (Mediascope, ЦС Платформа):

- **Смешное и животные** — главные темы клипов (62% и 38%). Капи — капибара с апельсинкой на голове: мемно, но это не чужая ИП. У неё есть эмоции: думает, радуется, пугается.
- **Удивление и неожиданность.** Башня мошенника эффектно рушится, а честное сообщение от бабушки ломает шаблон «всё во Входящих — ловушка».
- **11–14 лет: соревнование и статус.** Есть дуэль на одном телефоне: двое по очереди тянут башню, ответ первого скрыт («🙈 не подглядывай»), побеждает тот, кто ближе. Есть титулы.
- **8–10 лет: коллекционирование и кастомизация.** Гардероб Капи: за звёзды открываются апельсинка, очки, медаль, корона.
- **Контент — повод для социализации.** Карточка результата с квадратиками в стиле Wordle и вызовом «Сможешь прикинуть точнее? 😏» уходит в системное «Поделиться».
- **Язык.** Короткие фразы, мягкий сленг без грубости: «Имба!», «База!», «Вайб-чек пройден ✅».
- **Желейная анимация.** Башня тянется и пружинит, звёзды выскакивают по одной, звук каждого шага поднимается вместе с башней.

## Педагогика

- **Конкретное → наглядное → абстрактное** (подход CPA). Деньги сначала видны как высота башни рядом с эталоном, потом как число.
- **Оценка и прикидка** развивают чувство числа. Ребёнок сравнивает масштабы, а не вспоминает факты.
- **Формирующая обратная связь** сразу после действия: «почему так» и новая попытка без потери прогресса (установка на рост).
- **Безопасность как навык, а не страх.** Правило формулируется через признаки: незнакомец, «слишком выгодно», срочность, просят код или перевод.
- **Обучение со сверстниками** в дуэли: дети обсуждают, как считать, и спорят, кто ближе.

| Сессия 3–5 минут, можно переиграть | 8 заданий, «Сыграть ещё» даёт новые задания |

| Нет тёмных паттернов | Нет таймеров, обратного отсчёта и «ещё попытки за…». Ничего не подталкивает тратить |
| Нет ссылок, QR, iframe, новых окон | Нет |
| Нет брендов и чужой ИП | Капи — собственный персонаж, товары без брендов. Сберкот и свинки не используются |
| Нет оружия, 0+/6+ | Да |
| Нет сервера, рейтингов, лидербордов | Сравнение с собой (рекорд сессии) и с другом на одном телефоне |
| Персональные данные не уходят | Игра ничего не собирает и не отправляет |
| Портрет 360–430 pt | Вёрстка под 9:19,5, проверено на 360×640 и 390×844. Слева сверху не перекрываем кнопку «назад» приложения |

## Связь с приложением

Только пять стандартных событий, новых не добавляли:

| Событие | Когда |
|---|---|
| `CLOSE_EVENT` | Кнопка «Выйти» |
| `FINISH_EVENT` | Конец каждого захода (одиночного и дуэли) |
| `COMPLETED_EVENT` | Конец первого одиночного захода, **один раз** за открытие |
| `VIBRATION_EVENT` | Хорошая прикидка, рухнувшая башня, тап по Капи |
| `SHARING_EVENT` | «Поделиться»: `text` + `image` (JPEG data URL карточки с результатом) |

## Управление контентом (без релиза)

Весь контент лежит в [`game/content/levels.json`](game/content/levels.json): задания, главы, порядок заданий в заходе и дуэли, титулы, пороги гардероба, реплики Капи. Контент-менеджер правит JSON на CDN, и игра подхватывает его при следующем запуске.

Пример задания:

```json
{
  "id": "s1", "chapter": "save", "item": "🎧",
  "q": "Ты откладываешь 300 ₽ в неделю. Наушники стоят 2 400 ₽. Сколько недель копить?",
  "unit": ["неделя", "недели", "недель"],
  "ref": { "emoji": "🫙", "label": "1 нед. = 300 ₽", "value": 1 },
  "answer": 8, "max": 20, "step": 1,
  "explain": "2 400 ÷ 300 = 8 недель."
}
```

- `unit`: `"₽"` (башня из монет) или три формы слова (башня из блоков, один блок = одна единица).
- `msg`: сообщение из чата для «Входящих», `scam: true` — ловушка (правильный ответ 0), `shield` — правило-награда, `start` — с какой высоты начинается башня (у ловушки это обещанная сумма).
- `run` / `duel`: какие главы и в каком порядке идут в заходе.

## Запуск

Любой статический сервер в папке `game`:

```bash
cd game
python -m http.server 8080
```

Дальше откройте `http://<IP ноутбука>:8080` в песочнице ([Android](https://github.com/vveidi/sber-hse-hackathon-2026-android) / [iOS](https://github.com/vveidi/sber-hse-hackathon-2026-ios)). Параметр `?debug` показывает на экране каждое отправленное событие.
